HARDWARE & SOFTWARE MECHANISM

How Lumengrid Works

Lumengrid uses a closed-loop system: LDR ambient sensors detect light level, PIR motion sensors trigger interrupts when vehicles approach, and the ESP32 dynamically calculates high-frequency LEDC PWM dimming.

Interactive Signal Processing Pipeline

Click on any stage below to highlight its function in the hardware chain:

STAGE 1

LDR Sensor Input

Reads ambient lux via ADC1 (GPIO 34). Determines Day vs Night mode threshold.

STAGE 2

PIR Motion Interrupt

Triggers digital GPIO 13 interrupt upon vehicle or pedestrian motion detection.

STAGE 3

ESP32 FSM Logic

Executes finite state machine algorithm, checking battery level & safety caps.

STAGE 4

5kHz PWM Output

Drives MOSFET gate on GPIO 25 to adjust streetlight duty cycle (0%–100%).

Firmware C++ State Machine 

#include <Arduino.h>

// Pin & PWM Definitions
#define PIN_LDR 34
#define PIN_PIR 13
#define PIN_BATTERY 35
#define PIN_PWM_LED 25

void setup() {
  Serial.begin(115200);
  pinMode(PIN_PIR, INPUT);
  ledcSetup(0, 5000, 8); // 5kHz, 8-bit
  ledcAttachPin(PIN_PWM_LED, 0);
}

void loop() {
  int ldr = analogRead(PIN_LDR);
  int motion = digitalRead(PIN_PIR);
  int bat = analogRead(PIN_BATTERY);
  
  int duty = 0;
  if (ldr > 2000) { // Night
    if (motion == HIGH) duty = (bat < 1200) ? 128 : 255;
    else duty = 64; // Standby 25%
  }
  ledcWrite(0, duty);
  delay(500);
}
